# Status

Kiro Fabric supports one product: the Kiro Fabric Power for Kiro CLI v3.

- Session command: `kiro-cli --v3`
- MCP tools: `fabric_info`, `fabric_workspace`, `fabric_exec`
- Guest runtime: strictly checked TypeScript in QuickJS only; no alternate execution fallback
- Native file, edit, shell, web, and subagent capabilities: owned by Kiro outside Fabric
- Real-client qualification: explicit release gate; not claimed by ordinary CI
