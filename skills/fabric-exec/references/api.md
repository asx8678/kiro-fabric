# Checked execution API

`fabric_exec` accepts `code`, optional `strings`, `resultFormat`, `tokenBudget`,
`agentBudget`, and `display`. Use direct mounted provider calls when known and
`tools.describe({ref})` after a type or argument-shape error. Outputs are
bounded; retrieve a returned overflow ID with
`await tools.call({ ref: "artifacts.read", args: { id } })`. Cancellation and
unverified effects are failures.
